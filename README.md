# mojisashi（もじさし）

文章を貼るだけで、文字数を数える道具です。提出先のルールに合わせた数え方で、すぐに確かめられます。

https://mojisashi.app （準備中）

## こんな人のために

- レポートや作文を、指定の字数に収めたい学生
- 応募書類やエントリーシートを、決められた字数で書く人
- SNSに投稿する前に、文字数の上限を確かめたい人

## 約束していること

- **文章はどこにも送りません。** 数えるのは、あなたのブラウザの中だけです。応募書類のような、人に見せたくない文章も安心して貼れます。
- **登録はいりません。** 開いたら、すぐに使えます。
- **広告は最小限です。** 文字数を数えることと関係のないサービスへの案内は出しません。
- **待たせません。** 貼った瞬間に結果が出ます。

## 機能

機能ごとの使い方は、それぞれの機能のREADMEに書きます（準備中）。

## いまはやらないこと

- **AIで文章を書き直す機能。** 文章をサーバーに送ることになり、「文章はどこにも送りません」という約束と両立しないためです。
- **アカウントと、文章をサーバーに保存する機能。**
