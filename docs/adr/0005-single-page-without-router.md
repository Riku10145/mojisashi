# 1ページのアプリにし、ルーターを使わずにHTMLへ書き出す

mojisashi は、Vite と React で作る1ページのアプリにします。「文字数を数える」と「テスト用の文章を作る」は、ページを切り替えずに同じページに置きます。検索エンジンに内容を伝え、表示を速くするため、ビルドのときに React の中身を1回だけHTMLに書き出します。この書き出しは、ルーターやフレームワークを使わず、小さな仕組みで済ませます。

## Considered Options

- **Astro。** ページを先にHTMLにする作りが得意ですが、Vite と React で書くことを優先しました。
- **React Router v7、TanStack Start。** どちらもページをHTMLに書き出せます。TanStack Start は型安全なページの切り替えもできます。ただ、ページが1つなら、ルーターの設定や依存を増やす理由がありません。

ページを増やすことになったら、この判断を見直してください。
