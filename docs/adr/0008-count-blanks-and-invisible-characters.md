# 空白に見える文字は空白として、見えない文字は数えずに扱う

ADR 0002 では、文字を見た目の1文字で数えると決めました。ただ、空白に見える文字と、見えない文字の扱いは決めていませんでした。そのため、次のような文字が、どの数え方でも1文字になっていました。

- **改行しない空白（NBSP）。** Web や Word から貼った文章によく入っています。半角スペースと同じに見えます。
- **見えない文字。** ゼロ幅スペース、BOM、ソフトハイフン、文字の向きを決める記号などです。画面には何も出ません。

使う人には、どちらも見分けられません。「空白と改行を除いた文字数」なのに空白が数えられていたり、見えない文字のせいで数が合わなかったりすると、提出先の数え方とずれます。そこで、次のように決めました。

- **空白に見える文字は、空白として扱います。** Unicode が空白（Zs）に分ける文字、つまり半角スペース、全角スペース、NBSP、幅の違う空白などは、どれも空白です。タブと改行も、これまでどおり空白です。
- **見えない文字は、どの数え方でも数えません。** Unicode が書式の文字（Cf）に分ける文字だけでできた1文字は、見た目で1つに見えないためです。「👨‍👩‍👧」の中にある、絵文字をつなぐ見えない文字は、絵文字の一部なので、これまでどおり絵文字ごと1文字です。

ADR 0002 の「見た目で1つに見える文字を1文字と数える」は変わりません。この ADR は、見た目で空白に見えるものと、何も見えないものの扱いを足すだけです。

## Considered Options

- **NBSP だけを空白に足す。** よく出会う1文字だけを直す案です。ただ、幅の違う空白も見た目は同じ空白なので、Unicode の分け方にそろえました。
- **見えない文字を「空白と改行を含む文字数」では数える。** 文字列の中身に近い数え方ですが、使う人にも提出先の人にも見えない文字を数えることになり、ADR 0002 と合いません。
