# よくある質問の答えを `<details>` で畳む

よくある質問は、質問を押すと答えが開き、もう一度押すと閉じる形にします。質問が並ぶだけになるので、自分の知りたい質問を探しやすくなります。

開け閉めには、HTML の `<details>` と `<summary>` を使います。ブラウザが開け閉めするので、JavaScript も React の state も要りません。キーボードでも開け閉めできます。Chromium のアクセシビリティツリーでは、質問は開け閉めの部品として扱われ、開くと `expanded` が `true` になります。JavaScript を切っても動きます。

## ゆるめる守り

ADR 0013 のとおり、機能に要るので、2つの一覧に `details` と `summary` を足します。

- `guards/zones.ts` の app のゾーンで使える要素
- `scripts/dist-policy.ts` の、書き出した body に入れてよい要素

どちらの要素も、ブラウザからのリクエストを生まず、文章にも触れません。属性は足しません。`open` を使わないので、どの答えもはじめは閉じています。

## 変わること

- 質問は `<h3>` から `<summary>` になります。読み上げソフトの見出しの一覧には、質問が出なくなります。`<summary>` の中に `<h3>` を置く書き方は、ブラウザと読み上げソフトによって、見出しとボタンのどちらとして読まれるかが分かれるので使いません。
- 閉じた答えも HTML には入っています。検索エンジンも読めます。JSON-LD と `llms.txt` の文が本文にあることの確かめも、これまでどおり通ります。

## Considered Options

- **React の state でボタンと答えを出し分ける。** 開け閉めの見た目は自由に作れます。ただ、JavaScript を切ると開けなくなります。閉じた答えを HTML に残すか、`aria-expanded` をどう付けるかも、自分で決めることになります。
- **畳まずに並べたままにする。** 守りはゆるめずに済みます。ただ、質問が増えるほど探しにくくなります。
