# ページ間のリンクを説明つきのカードにし、トップの紹介をページの下へ移す

ADR 0020 は、`/` と `/dummy-text/` を、説明の文の中のリンクで行き来すると決めました。これを、それぞれのページの機能のカードのすぐ下に置く、説明つきのカードの形のリンクに変えます。あわせて、`/` の紹介の段落を、ページの下の「mojisashi について」のカードへ移します。

持ち主がスマホで dev環境を開き、2つのことに気づきました。

- 説明の文の中のリンクは、ほかの文と見分けにくく、目立たない。
- 見出しの下の説明が長く、文章の欄までの距離が長い。375px の幅では、紹介の段落だけで5行になります。

## 決めたこと

- **リンクは、説明つきのカードにします。** `src/platform/` の `PageLink` は、Mantine の `Card` で `<a>` を描きます。行き先のページの名前、何のためのページかを言う1文、右向きの矢印を並べます。カード全体が1つのリンクで、役割は `link` です。行き先は `"/"` と `"/dummy-text/"` だけを受け取ります（ADR 0022）。
- **リンクは、機能のカードのすぐ下に置きます。** `/` では文字数を数えるカードの下、`/dummy-text/` では文字数を決めて作るカードの下です。
- **`/` の見出しの下には、約束の1文だけを置きます。** 「文章はサーバーに送らず、あなたのブラウザの中だけで数えます。」は、文章を貼る前に読めるように、見出しの下に残します。
- **紹介の段落は、ページの下へ移します。** `llms.txt` と JSON-LD の `description` が、この段落をそのまま引いています。ビルドは、その文が本文の1つの段落にあるかを確かめます（ADR 0015）。そのため、文は変えずに、置く場所だけを変えます。
- **`/dummy-text/` の説明は変えません。** 3つの文は JSON-LD の `description` と同じで、`llms.txt` もその最初の文を引いています。

## Considered Options

- **ページの名前だけのボタンを、見出しの下に置く。** 一度この形にしました。持ち主から、「テスト用の文章を作る」のボタンは、押すとその場で文章を作るものに見える、何のボタンか分からない、と指摘を受けました。
- **説明つきのカードを、見出しの下に置く。** いちばん目立ちます。ただ、幅390px、高さ664px の画面で、文章の欄の上端が 429px まで下がります。機能のカードの下に置くと、310px です。`/` に来る人のほとんどは文字数を数えに来るので、数える欄を先に見せます。
- **紹介の段落を短く書き直す。** 見出しの下は短くなります。ただ、`llms.txt` と JSON-LD の文も同じに書き直すことになり、検索の結果に出る文も変わります。
