# 文字数を数える

貼った文章の文字数を、2つの数え方で同時に表示する機能です。

## 使い方

1. 文章を貼るか、そのまま書く
2. 2つの数え方の文字数を見る

## 数え方

- **空白と改行を除いた文字数。** 半角スペース、全角スペース、タブ、改行を数えません。
- **空白と改行を含む文字数。** 改行は、どのパソコンで書いた文章でも1文字です。

どの数え方でも、見た目で1つに見える文字を1文字と数えます。「👨‍👩‍👧」のような組み合わせの絵文字も、濁点を組み合わせて書いた「が」も1文字です。

## 目標の文字数

目標の文字数を入れると、あと何文字か、何文字オーバーかを表示します。目標の文字数は、1から1,000,000までの整数で入れます。比べる数え方は、最初は「空白と改行を除いた文字数」です。「空白と改行を含む文字数」に切り替えられます。

## 例：エントリーシートを400字以内で書く

1. 目標の文字数に400と入れる
2. 書いた文章を貼る
3. 「12文字オーバー」と出たら、12文字削る

## 文章の扱い

文章はサーバーに送らず、ブラウザにも残しません。ページを閉じたり再読み込みしたりすると、文章は消えます。
