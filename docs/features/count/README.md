# 文字数を数える

貼った文章の文字数を、2つの数え方で同時に表示する機能です。

## 使い方

1. 文章を貼るか、そのまま書く
2. 2つの数え方の文字数を見る
3. 文字数を合わせたら、文章の欄の右上の「文章をコピー」を押して、提出先に貼る

## 数え方

- **空白と改行を除いた文字数。** 空白、タブ、改行を数えません。空白には、半角スペースと全角スペースのほか、Web や Word から貼った文章に入る、改行しない空白（NBSP）や、SNS で空行を作るのに使う「ㅤ」（ハングルの埋め字、U+3164）も入ります。
- **空白と改行を含む文字数。** 改行は、どのパソコンで書いた文章でも1文字です。

どの数え方でも、見た目で1つに見える文字を1文字と数えます。「👨‍👩‍👧」のような組み合わせの絵文字も、濁点を組み合わせて書いた「が」も1文字です。ゼロ幅スペースのような、画面に何も出ない文字は、どの数え方でも数えません（ADR 0008）。

## 目標の文字数

目標の文字数を入れると、あと何文字か、何文字オーバーかを表示します。目標ちょうどのときは、「ちょうど400文字」のように出します。目標の文字数は、1から1,000,000までの整数で入れます。入れられる範囲は、欄の上にはじめから出ています。ほかの値を入れると、差は出さずに、欄の下に「1から1,000,000までの整数を入れてください」と出します。比べる数え方は、最初は「空白と改行を除いた文字数」です。「空白と改行を含む文字数」に切り替えられます。

## 文章をコピーする

「文章をコピー」を押すと、文章の欄の中身を、改行も空白もそのままクリップボードに入れます。コピーできると「コピーしました」と出ます。文章を書き換えると、この表示は消えます。文章の欄が空のときは、押せません。

## 例：エントリーシートを400字以内で書く

1. 目標の文字数に400と入れる
2. 書いた文章を貼る
3. 「12文字オーバー」と出たら、12文字削る
4. 「文章をコピー」を押して、応募のページに貼る

## 文章の扱い

文章はサーバーに送らず、ブラウザにも残しません。ページを閉じたり再読み込みしたりすると、文章は消えます。
