# テスト用の文章を作る

開発中に、入力欄の文字数の上限を試すための機能です。決めた文字数ちょうどの文章を作ります。

## 使い方

1. 作りたい文字数を入れる（100,000文字まで）
2. 文字の種類を選ぶ（はじめは日本語）
3. 「作る」を押す。作った文章が、下の枠に出る
4. 「コピー」を押して、試したい入力欄に貼る

## 作る文章

文字の種類は2つです。

- 日本語：「あいうえお」をくり返し、決めた文字数で切ります。7文字なら「あいうえおあい」です。
- 英語：小文字の英字（aからz）をランダムに並べます。数字や記号は入りません。

作った文章は、枠の中に全部出ます。長いときは、枠の中をスクロールして見ます。

## 例：200文字までの入力欄を試す

1. 200と入れて作り、入力欄に貼る。200文字すべて入るかを見る
2. 201と入れて作り、入力欄に貼る。201文字目で止まるか、エラーが出るかを見る
